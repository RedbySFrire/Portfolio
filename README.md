# 🌟 Portfolio Agent // FC-93

Un portfolio interactif et dynamique inspiré par l'esthétique urbaine et cyberpunk du jeu vidéo **Zenless Zone Zero (ZZZ)**. Développé sous forme de Single Page Application (SPA), ce projet met en avant mes compétences en développement web, administration système et réseaux.

## 🚀 Fonctionnalités
- **Design System ZZZ :** Thème sombre contrasté avec accents jaune acide (`#D8FF00`) et orange (`#FF5500`), trames manga (halftone) et effets d'écran cathodique (scanlines).
- **Navigation SPA :** Changement d'onglets instantané sans rechargement de page.
- **Animations fluides :** Transitions physiques (effets de ressort et d'inertie) au survol et à l'ouverture des sections.
- **Architecture modulaire :** Séparation claire entre les données (tableaux de compétences, d'expériences) et l'interface visuelle.

## 🛠️ Stack Technique & Outils

- **Cœur du projet :** React (v19) propulsé par Vite.
- **Stylisation :** Tailwind CSS (v3) pour une intégration rapide via des classes utilitaires.
- **Animations :** Framer Motion pour des animations basées sur la physique.
- **Iconographie :** Lucide React.
- **Déploiement :** GitHub Pages (`gh-pages`).

## ⚙️ Prérequis
Assurez-vous d'avoir installé sur votre machine :
- **Node.js** (version 18 ou supérieure recommandée)
- **npm** (inclus avec Node.js)
- **Git**

## 💻 Installation et Démarrage local

**1. Cloner le dépôt**
Ouvrez votre terminal et clonez le projet en local :
```bash
git clone https://github.com/RedbySFrire/portfolio.git
```

**2. Accéder au dossier du projet**
```bash
cd portfolio
```

**3. Installer les dépendances**
Téléchargez toutes les bibliothèques nécessaires (React, Tailwind, Framer Motion...) :
```bash
npm install
```

**4. Lancer le serveur de développement**
Démarrez le serveur local avec le Hot Module Replacement (HMR) :
```bash
npm run dev
```
Le terminal affichera un lien (généralement `http://localhost:5173/`). Cliquez dessus pour visualiser le portfolio dans votre navigateur.

## 🌐 Déploiement

Ce projet est configuré pour être déployé automatiquement sur GitHub Pages. Pour compiler le code final et le mettre en ligne, utilisez la commande suivante :
```bash
npm run deploy
```
*Note : Cette commande exécute d'abord `npm run build` pour générer les fichiers de production dans le dossier `/dist`, puis les envoie sur la branche `gh-pages`.*
